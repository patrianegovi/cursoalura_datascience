# Estudos em Data Science 📊

Repositório dedicado aos notebooks, exercícios práticos e anotações desenvolvidos ao longo das aulas de Ciência de Dados.

## Conteúdo
* **Manipulação e Limpeza de Dados:** Uso de bibliotecas como `Pandas` e `NumPy`.
* **Análise Exploratória e Visualização:** Gráficos e estatísticas descritivas.
* **Modelagem:** Introdução a algoritmos de Machine Learning.

## Créditos
Códigos baseados nas aulas e desafios propostos na formação de Data Science, adaptados e documentados para fins de estudo.
